# ML-Lab10

This project applies the Support Vector Machine (SVM) algorithm on the famous Iris dataset using Python and Scikit-learn.

## Project Overview

The notebook includes:

- Loading and exploring the Iris dataset
- Visualizing the data using Seaborn
- Splitting the dataset into training and testing sets
- Training an SVM model
- Evaluating the model using:
  - Confusion Matrix
  - Classification Report
- Improving the model using GridSearchCV

## Libraries Used

- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## Dataset

The dataset used is the Iris dataset available in Seaborn.

## Results

The SVM model achieved very high accuracy in classifying the flower species.  
GridSearchCV was also used to test different parameter values and optimize the model.
